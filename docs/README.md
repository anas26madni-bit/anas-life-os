# Documentation

The authoritative Project Bible is stored in `project-bible/`. Supporting decision, traceability, roadmap, and handover records are separated so their authority is unambiguous.

- `project-bible/` — unchanged approved Master documents
- `masters/` — document-control guidance; canonical files remain in `project-bible/`
- `decisions/` — approved, pending, and controlled open-issue registers
- `traceability/` — cross-Part requirement mapping
- `roadmap/` — schedule support records
- `handover/` — complete self-contained continuity package

When summaries conflict with an approved Master, the authority order in the Project Bible applies. Part 11 exclusively governs schedule.
